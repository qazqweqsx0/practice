# Рабочий журнал

## Решения

- После оценки карточка сохраняется и уходит из очереди на сегодня. Stats: к повторению сегодня, на 7 дней, серия дней с повторениями.
- Реализовал алгоритм интервалов в духе SM-2: от оценки (`again` / `hard` / `good` / `easy`) пересчитываются ease, interval и дата показа. При `again` interval=0 — карточка остаётся «на сегодня», не уходит из очереди.
- Поиск: `GET /notes?q=` — подстрока в названии или теге; в UI одно поле, автопоиск, «Сбросить» показывает все заметки.
- Редактирование заметок через «изменить» (PUT). «В повторение» — карточка из заголовка и текста, сразу в очередь.
- Блок заметок можно свернуть.

## Допущения

- Один пользователь, auth не делал — усложнил бы MVP.
- Связи между заметками (`links`) есть в API, в UI не выводил — важнее end-to-end повторение.
- Карточки из заметки — быстрый старт без отдельного редактора карточек.

## С чем поспорил / что отклонил

- Автоудаление заметок через 30 дней — через месяц как раз начинаешь забывать, для этого и нужны карточки.
- ИИ-конспекты — внешний сервис, ключи, качество; быстрее написать заметку самому.
- Обложки книг и автословарь — внешние API, не core loop.

## Мнение

- В брифе много «было бы круто», но главная проблема — «читаю и через неделю пусто».
